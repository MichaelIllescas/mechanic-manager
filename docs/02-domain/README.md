# Domain Documentation

Documentación del modelo de negocio necesario para el MVP.

## Contenido actual

- [Modelo de Dominio](01-modelo-de-dominio.md)

## Criterio

El dominio se documentará de forma simple y alineada con el lenguaje del negocio.

No se incorporarán patrones de DDD táctico, eventos de dominio o estructuras adicionales por anticipación. Si el producto crece y una necesidad concreta lo justifica, la documentación evolucionará junto con el código.
